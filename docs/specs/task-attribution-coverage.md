# 提高任务时间归属覆盖率

基线 `54b3e779a02d818692b940fa93b13ecf53bcde18`。用户授权实现、测试。

- 已识别任务的关键帧之间若仅有意料外的新图片未进入模型输入，且采样连续、应用状态无矛盾、总间隔不超过3分钟，可将时间标为邻接推断并归入该任务；实际选中却无法识别的图片是语义边界，不跨越。任务变化仍优先使用应用切换事件定位，否则用中点，单帧不编造时长。
- 历史报告只按已存归档证据升级计算，不重新识图、不增加模型请求、不重写原始活动解释；无法恢复关键帧选择事实时保持原有不确定性。
- 未归类工作再分两层：已知前台应用但仍无法确定任务时为「仅应用」，其余为「其他未归类」。两者都计入电脑工作估时，不进入任务排行或连续专注统计。
- status、today、报告、JSON 与 Notion 使用同一分解：已归类任务 + 仅应用 + 其他未归类 = 电脑工作估时；报告可以展开应用归属区间。
- 关键帧选择保持时间分布与应用边界优先，同时允许一定量可见内容变化增加最多两张，仍受每批最大图片上限约束；不增加模型调用次数。
- 合成回归覆盖跨未选图片补估、选中未知图阻断、跨应用、三分钟边界、应用级归属、时区显示、关键帧预算及报告筛选。全量race、macOS/Windows静态检查和合成报告浏览器检查；不读取真实截图或正文。
