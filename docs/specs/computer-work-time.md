# 电脑工作估时与重启

基线 `6040575d2f6c037c0851af8e7714a8b61b135e30`。用户授权实施、测试、提交、发布、更新本机并重启。

- 工作均基于电脑。锁屏、息屏、休眠及连续无键鼠输入满20分钟后按未工作处理；恢复输入后继续，前20分钟可包含阅读/思考估时。新增明确配置入口，本机由5分钟调整为20分钟，保留其他配置。
- 电脑工作估时与任务归类分开。连续且间隔有界的可用采样支持工作估时，即使任务未归类；单帧不编造时长，不跨越长缺测、异常、暂停或停止。未知任务不自动分配到已有任务，不增加模型请求。
- 独立返回工作总估时、已归类、未归类、明确离开和采集不足；区间去重、时区/跨日/DST裁剪一致，已归类+未归类=工作估时。原 estimated_seconds 保留任务估时含义，新增 work_time，不改写历史活动解释。
- status、today、日/周/月/时段报告使用同一计时规则；实时本地汇总可包含待整理和草稿。报告保持系统字体、克制布局、键盘和移动端可用，说明估时及分类缺口。
- Notion 输出已整理记录的工作估时，沿用原批次来源保护与备注保留；未整理部分仍以待补齐提示，避免未提交来源被覆盖或伪造任务归属。
- 增加 daylog restart：对已运行的后台保留暂停到期时间和登录自启配置，停止后等待旧进程释放，再启动并验证新PID/启动时间；不因重启恢复暂停。未运行时提示 start；前台运行且无后台配置时不悄悄转换。更新恢复复用可靠启动检查。
- 合成回归覆盖20分钟边界、重复帧/未选新图/跨应用、未知与低置信任务、缺测与锁屏、待整理/草稿、跨日/DST、汇总及Notion一致性、暂停/重启失败和CLI契约。执行全量race、平台检查、隔离运行与安装验证，合成报告浏览器复验。
- 按 docs/releasing.md：最终main提交三平台CI成功后打标签，完整签名发布检查通过，再核对下载附件并公开。更新本机后只改空闲阈值，验证版本、签名、后台、暂停、登录自启及Notion时间表。无真实截图/日记正文或凭据输出，不触发额外模型分析作为测试。
