## 判断与实现

|建议|判断|实现|
|---|---|---|
|UX-1|成立。浏览器复现：筛“写代码”有 4 项，点击讨论任务错误变成 0 项。|排行下钻调用统一 reset，清除旧搜索、分类、分页及未知区间状态；显示任务名、匹配数和后续手动条件。焦点移至完整记录标题。用户进入后仍可按交集筛选，日期/周期切换和清除恢复统一状态。|
|UX-2|采纳。有待整理/失败时，原入口过深。|标题附近显示快照时间、待整理及其失败/中断子集，提供展开并聚焦失败原因的按钮；重新生成命令按当前日期/周期或 range 边界生成，并说明刷新浏览器不会更新数据。失败说明前置到“关于数据”的开头；命令始终可选择，复制成功和失败都明确尚未执行。自定义数据目录提醒沿用原 `--data` 参数，不在报告里写入本机路径或凭证。|
|UX-3|采纳。原 23 个时间轴标记都只靠 title，无法通过键盘查看等效说明。|图下使用原生 details/summary 展开按时间排序的区间与未估时活动清单；分别标注连续观察、含区间推断以及时长未估。原色块/点保持紧凑，不增加密集 Tab 停靠点。打印展开清单，结束后恢复原折叠状态。|

无整体不采纳项。未采用放大每个细碎标记或给每个点增加焦点的方案，避免改变时间比例、堆积触控目标；未增加页面直接重试或自动刷新数据能力，保留离线快照边界。系统字体、配色、列表层级保持现有约定。

## 验证与复现

生成两份合成资料，以本地 HTTP 提供：

```sh
go run ./scripts/report-demo OUTPUT/report.html
go run ./scripts/report-demo OUTPUT/failure.html --failure
```

在现有 Playwright runner/tool 中，把 `scripts/verify-report-ui.js` 作为接收 `page` 的函数执行，当前页需在两份资料的同一目录。无需给 Go 项目安装 Node 依赖。浏览器工具的文件入口若限制根目录，可使用其支持的内联 code 参数运行该函数。

- `go test ./internal/journal -run 'Test.*(HTML|Report|Recap|Period|Overview)' -count=1` 通过。
