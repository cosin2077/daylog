# Daylog 0.9.0 全链路审查与修复

审查日期：2026-10-18。固定基线：`c90b85852d9c039dc4f95eb29a08ffed3a05780d`。GPT-6-astra 独立审查，主代理复现、修复与验证，随后进行两轮对抗复核。最终复核未发现新增的重要阻断项；这不意味着所有平台场景已被穷尽。

## 已采纳：4 项 P1、10 项 P2

|级别|发现与证据|修复|
|---|---|---|
|P1|Windows 只检查前台排除应用，GDI 整屏仍可能包含后台可见的禁用窗口。|采集前后枚举窗口，检查与截图区域相交的禁用/未知窗口；无法确认时丢弃整帧。窗口截图同时核对窗口位置与前台身份。|
|P1|macOS 原生应用排除大小写敏感，与 Go 检查不一致。|统一大小写与空白处理，检查目标 owner 和采集后的前台状态。|
|P1|环境查询失败时提前返回，暂停可能没有取消在途分析；分析注册还有竞态。|控制端立即取消，环境失败也取消；同一把锁内复查暂停状态并登记取消函数。最终写帧与暂停确认串行化。|
|P1|更新只保留运行状态，新进程会丢失原暂停。|原子持久化 `pause.json`；首次采集前恢复，损坏时停止启动；显式 start 清除暂停。更新前保存旧 daemon 暂停，重启等待接受 paused。|
|P2|API 请求/读取响应被取消后记录为普通失败。|保留 context cause，状态为 interrupted，不增加失败轮次；请求与 body 取消都有回归。|
|P2|真实 deriveReport 丢弃低置信 task 标签，90 秒边界误给高置信任务补 45 秒。|保留低置信边界；v3 重算先移除旧 inferred spans。归档恢复证据与原时间边界；缺归档时对旧版含 low 的空标签样本保守保留未知。历史文件不重写。|
|P2|采集期间切换应用，保存的 app 元数据仍来自截图前。|采集后复查环境，身份变化或权限/锁屏状态异常则丢弃；指定窗口继续按窗口 ID 标记。|
|P2|进程崩溃遗留 jobs/analysis-* 原图，既不清理也不计容量。|持 analysis.lock 清理失去所有者的临时目录；启动与下一轮分析也回收；统计临时占用。单批图像工作区另限 12 MiB，保证原图满额仍能分析排空队列。|
|P2|macOS 两个并发更新都成功，较旧包最后覆盖较新包。|更新锁覆盖停止、替换、重启及就绪回调。替换前控制连接失败时检查 daemon 锁与服务状态，不能确认已停则拒绝。|
|P2|Windows 首装未保存默认 feed，普通 update 不可用。|共享默认正式更新源；旧空配置也回退默认源，自定义源保持优先。Windows 安装验证新增默认源断言。|
|P2|自定义时段页头没有完整起止边界。|显示起止日期、时间、UTC offset 和结束边界语义；跨日轴显示日期。|
|P2|HTML 用当天零点 UTC offset 换算所有刻度，DST 日午后偏一小时。|后端按报告日历时区生成轴刻度；春秋 DST 回归均覆盖，浏览器使用序列化标签而非查看者时区。|
|P2|月中生成历史报告时，导航提供完整跨月周，但月底之后的数据未加载。|存储读取与日历范围扩展至当月最后一天所属周末；日历与实际跨月活动加载都有测试。|
|P2|手机日期箭头、详情、折叠等目标过小；辅助文字对比偏低。|移动端主要控件高度至少 44px，详情按钮不换行；提高辅助文字对比。320px/375px 日周月均无横向溢出。|

修改集中在 `internal/native`、`internal/journal`、`internal/update`、`cmd/daylog` 与隔离验证脚本。未变更版本号。

## 保留与未验证项

- Windows GDI 采用保守拒绝：完全被遮挡的禁用窗口也可能导致跳过截图；这是隐私优先的明确取舍。本轮无 Windows 实机，窗口像素、PowerShell 安装及会话行为仍需 Windows runner/实机验证。
- 当前开发包的 macOS 录屏预检为 false；未申请、更改或绕过 TCC。真实桌面截图与多屏/窗口像素排除未验证，不能用合成夹具代替该结论。
- 本轮不对模型语义准确率、长时间电池耗电、热状态/锁屏硬件事件或所有 Agent 版本作保证。两个真实调用证明当前本机 Claude/Hermes 可走通匿名图片链路。
- 60 天 × 32 批 × 10 活动的合成压力样本，BuildOverview 约 1.49 秒，JSON 约 48.92 MiB。记录为容量边界：尚未证明浏览器不可用，不在本轮进行风险较大的报告数据结构重构；后续应专门测浏览器峰值与加载时间。
- 保持用户既定的克制报告风格、系统字体与信息层级，不为了审美规则更换设计系统。界面有清晰层级、渐进披露和文本标签，无装饰渐变/嵌套卡片堆叠；本轮只修影响理解与操作的问题。
- 一次子代理夹具未隔离 Agent 搜索路径，意外调用本机 Claude；输入仅为合成渐变图片和合成元数据。已明确记录，该次不计受控验证，并改用空搜索路径复测；临时数据已清理。
