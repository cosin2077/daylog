# 0.8.0 UX 评审处理

依据 2026-10-16 的 0.7.0 产品/CLI 评审和日报草图实施。草图来源数字只作布局参考，实际统计使用已有记录。

| 评审项 | 判断与实现 |
| --- | --- |
| 首屏像数据审计 | 采纳。结论句、活动估计时长、最长连续一段、任务切换优先；系统状态放页脚，方法和未知区间折叠。 |
| 分类七格过重 | 采纳。色条与最多五类图例，小于 5% 的项目并入“其他”；无可估时记录不绘制空分类块。 |
| 总结与分类不一致 | 成立。旧总结偏向任务标题或次数；改按分类有效估计时长生成，与色条同口径，不再重复拼接建议。 |
| 小事墙与重复明细 | 采纳。真实应用来源 Top 3，其他来源和切换明细折叠，数量保持守恒。 |
| 最长专注与平均切换间隔 | 调整采纳。使用“最长连续一段”和有观察依据的切换次数；连续观察不能证明深度专注，未知时段也不能充当平均间隔的分母。 |
| 家人/群聊/面板分组 | 仅采纳真实应用聚合。应用名不证明关系或动机，不把草图分组写成事实；缺失来源明确显示“来源未记录”。 |
| 当天时间轴与任务排行 | 采纳。全宽任务 Top 5 前置，可展开全部并联动明细；时间轴裁到首末活动，显示有效 spans、单帧点与最长连续区间，长标题完整换行。 |
| 活动明细噪音 | 采纳。默认折叠，移除时长列；保留搜索、分类/任务筛选、分页和详情。打印展开全部匹配记录，取消后恢复分页与折叠。 |
| 周/月缺少变化 | 采纳。周报每日活动时长/切换趋势，月报日历热力图，不绘制未来日期。关键数字比较前一天/上周/上月；未结束周期按本地日历进度对齐，上月较短时截止月末。无可比记录不编造百分比。 |
| 一条可执行建议 | 采纳。同一小时至少两次短时切换时，提供时间点与集中处理临时事项的建议；不将切换直接判为坏习惯。 |
| 完成后自动补进来 | 未采纳此承诺。HTML 是离线快照，需重新运行 daylog report，避免用户等待不会发生的更新。 |
| 术语与帮助 | 采纳。常用文案统一“整理/段/截图”，高级帮助分日常、排障、Agent 集成、服务与验证；所有命令有自己的 -h / help COMMAND。JSON 旧字段不改名。 |
| status 与 pending 失败矛盾 | 成立。共享中断/失败判定，旧 canceled 队列也不计失败；status 实时读取队列，避免后台计数滞后。默认六行，--verbose 看详情。 |
| pending 默认一条和编号噪音 | 采纳。默认最多十段，普通输出显示时间、截图与状态；编号和调用计数保留在 JSON。 |
| today 长免责声明 | 采纳。默认显示日期、项数、待整理与任务，方法仅在 --explain 展开；--full 与完整 JSON 保留。 |
| today 179 / report 175 | 当前同份 10-15 数据只读核对为 180 / 180，未复现原快照差异，不能断言原因。确认了零长度单帧被 period 排除的边界并修复；today 展示及新增 activities/activity_count 复用 report 裁剪口径，跨午夜与单帧有回归，原始 reports 保留。 |
| 自然参数与未知 flag | 采纳 today yesterday / report week/month，支持选项交错，显式日期/周期冲突报错。未知选项保留原横杠数量并显示支持项，不回显值；已有近似命令建议继续保留。 |
| 空日期空报告 | 采纳。无活动、待整理或未封段截图时提示最近可看日期，不覆盖已有 HTML；JSON 仍返回结构化空结果，退出 0。 |
| pause 0 和恢复确认 | 成立。CLI 与控制服务均拒绝 0、负数及超过 1440 分钟。同步确认暂停/恢复状态，提示自动恢复时刻与 resume。 |
| analyze 不存在编号 | 成立。模型/原生环境检查前验证记录，缺失指向 pending；损坏文件与不存在分开，不建议重试不存在编号。 |
| doctor 对齐与模型检查 | 部分采纳。汉字显示宽度对齐，展示系统策略、模型安装、最近响应与下一步。不默认发送截图或付费请求，不将历史成功说成当前连通。 |
| config 分组和密钥 | 采纳。分常用/高级，JSON 默认打码；完整导出显式用 --json --show-secrets。打码配置导入保留现有密钥，直接设置占位符会拒绝。 |
| update、时间与单位 | 采纳“已是最新版本”，本地时间不重复时区缩写，状态磁盘使用十进制 KB/MB/GB。 |

## 验证边界

统计、参数、状态和配置由 Go 回归覆盖。真实 Chrome 使用本机 HTTP 合成报告验证日周月、空日期、长标题、任务筛选、搜索、分页、来源折叠、详情和打印预览恢复。1440×1000 与 390×844 为实际 CSS 视口，均无横向溢出；手机默认日报约 1516px 高。该高度来自本轮合成数据，不能当作原始用户日报的等量前后对比。

没有新增模型请求、修改用户 ~/.daylog、更换本机运行时或同步本机已安装 skill。Windows 原生执行、安装和自更新由平台 CI 验证，不能据此宣称 Windows 用户桌面、多屏、电池或真实模型识图已实测。
