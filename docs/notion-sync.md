# Notion 每日日志同步

## 配置

在 Notion 创建一个普通页面（例如 Daylog），为 API 连接授予该页的读取、插入和更新权限。在终端运行：

```sh
daylog notion setup
```

按提示粘贴目标页面链接与 API Token。Token 隐藏输入，仅保存在 macOS 钥匙串或 Windows 凭据管理器中，和 AI Key 分开。不要把 Token 放进命令行参数、聊天或 config.json。

脚本可使用 `daylog notion setup --page <页面链接> --token-stdin` 从受保护的标准输入传递 Token。默认捕获本机时区；也可明确指定 `--timezone Asia/Shanghai`。`--since YYYY-MM-DD` 决定补传起点，默认从昨天开始；不会默认上传全部历史。

配置成功会在目标页下建立「Daylog 日志」和「Daylog 活动」两个数据库。只采用带本数据源标识的数据库，不挪用用户已有的同名库。初次配置在完成权限/字段检查前不启用自动同步，部分成功后再次 setup 会接续已有库。

## 同步内容

日志数据库每天一行，名称固定为 `YYYY-MM-DD · 日报`；保存时区、估计/插值/推断/未估时秒数、旧版覆盖、活动与批次数、待整理/失败数、同步状态及最后同步时间。轻量概述只描述记录数量和证据边界，不另调用模型做深度分析。

活动数据库每个原始活动片段一行，关联每日日志。保留具体标题、描述、动作、目标及 task_id、类别、时间边界、秒数、估时区间/来源、置信度、不确定性、应用、可得的模型/提示版本、证据图数。缺少时长用「未估时」标记，未知模型不猜测。未将合并后的显示行作为稳定身份，便于后续定量分析、筛选和导出。

不上传截图，不额外调用视觉模型。日记的页面正文留给人工复盘；后续同步仅维护 Daylog 属性，不清空或替换正文。字段名称/类型属于同步契约，改名后请恢复或重新配置。源记录到期不等于请求删除云端历史，默认保留云端已写记录。

## 调度与补传

保持 Daylog 后台运行（登录自动启动可用 `daylog start --login`）。每天保存时区的 00:00 后检查前一天；开机、唤醒、断网恢复后继续检查已结束的日期。只有电脑和 Daylog 进程运行时才能同步，不会唤醒已关机的电脑。

同步日期作为持久化任务标识，补传时不会改叫执行当天的“昨天”。夏令时按日历而非固定24小时推进。没有记录的日期不建空页。先上传已有结果，若后续分析补齐，会更新同一天与原活动行。默认每次处理最多4个变化的日期，批次重试有退避；未变化的内容不反复写入。

```sh
daylog notion status
daylog notion status --json
daylog notion sync                  # 手动同步昨天
daylog notion sync --date 2026-10-18
daylog notion sync --date 2026-10-18 --dry-run  # 只预览，不联网、不读凭证
daylog notion check
daylog notion disable
```

自动同步独立于截图/模型分析，屏幕锁定不会被当成同步完成；系统休眠会延后到恢复后。停用不会删除云端页面，已经发出的请求可能完成。

## 故障与额度

- 普通断网和服务错误会自动退避；429/529 尊重 Retry-After，包括超过1分钟的工作区限制。
- Token/权限、字段错误或免费工作区区块限制会暂停自动写入，避免无限重试。修正后重新 setup 或手动 sync；状态中可见失败原因。
- 若创建请求响应丢失，先根据稳定标识或 Notion 返回的已提交 ID 核验。无法确认时保留待核验回执，不盲目重复创建；只在人工确认远端不存在后使用 `--retry-uncertain`。
- 单成员免费工作区当前不限页面/区块；多成员免费工作区有累计1000块限制且删除不恢复。附件单个5MB；本功能不上传附件，也不使用 Notion AI。
- 100个活动/天约为每年36,500个活动行，加365个日报和少量日报正文块。数据源很大时要按日期筛选，不能把不限区块等同于不限性能。
- 本地报告默认保留90天。补传受现存本地元数据约束；无法恢复已经清理的数据。同步不取代独立备份。

官方规则核对日期：2026-10-20。API 固定使用 `Notion-Version: 2026-03-11`，通过 data source 建页。参考：[区块限制](https://developers.notion.com/reference/workspace-block-limits)、[请求限制](https://developers.notion.com/reference/request-limits)。

## 扩展接口与验证

`internal/exports` 提供版本化日快照和小型 Sink 接口；调度负责日期、持久化、退避与状态，适配器负责远端转换和对账。目前内置 Notion，不引入任意代码加载、插件市场或单独常驻服务。未来输出目的地可复用快照和调度，无需读取截图。

自动测试使用独立数据目录、合成日记、内存凭证与 HTTP 夹具，覆盖两库创建/重入、121行分页、迟到结果更新、日期/DST、断网与限流、权限/额度、创建响应丢失、正文保护和Token不落盘。它们不等于用户真实 Notion 工作区的端到端验收；首次实际连接仍需用户提供 Token 和目标页。
