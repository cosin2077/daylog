# 0.6.1 CLI 评测核验

核验日期：2026-10-16。以 b485357 的源码为基线核对 0.6.1 体验报告；以下修改随 0.7.0 提供。评测修复先用隔离数据验证，发布与本机升级的验收另记于 VALIDATION.md。

| 评测条目 | 判断与处理 |
| --- | --- |
| 1. 大量“观察估计约 0 分钟” | 成立：CLI 对秒数做整数分钟除法，把未知时长和不足一分钟都显示成零。未知显示“时长未估”，有效短区间显示秒数；增加日记摘要和未知区间说明。高未知占比本身不是估时算法错误，不会为提高覆盖率虚构时长。 |
| 2. Claude/Hermes 超时与解析 | 超时成立，但“stream-json 解析失配导致所有超时”不成立。原代码已支持最终 result，相关日志既有成功结果，也有只有初始化/重试、没有最终结果的超时。补强空结果拒绝、终态错误分类、重试事件计数与超时说明；增加 `config --agent-timeout` 入口。原本 `agent.timeout_seconds` 已可配置为 10–600 秒，不盲目延长默认时限。未实际请求用户的模型，不能声称真实服务超时已解决。 |
| 2a. Hermes Unknown toolsets: none | 警告成立，未证明它导致超时或解析失败。当前本机 Hermes 的空值/省略 toolsets 会恢复默认工具；不存在已核验的稳定空工具集替代参数。本轮保留约束，避免仅消除警告却启用默认工具。补测警告与文本增量不覆盖最终 result；后续需 Hermes 明确的禁用工具接口，再验证真实调用。 |
| 3. pending 显示数量、尝试与失败 | 展示问题成立；调用次数和整轮失败次数本来就是不同计数，取消不计整轮失败，2 次/0 轮并不矛盾。明确标签和取消含义，显示查看全部的 `--limit` 命令，补齐超时、取消、结果缺失、输出过大及 Agent 错误的说明。失败通知采用白名单原因文案，不包含模型文本或凭据。 |
| 4. doctor 英文错误且无下一步 | 成立。原生启动失败、超时或无结果时显示中文原因、应用路径、访达打开及只读签名检查建议；`--json` 返回 `ok:false` 与错误代码，不假造权限/电源状态。测试注入 LaunchServices 失败，不重新授权，也不声称已修复具体机器的原生启动故障。 |
| 5. status --json 在停止时输出纯文本错误 | 成立。确定停止时返回退出码 0 与 `running:false`、`state:"stopped"`，保留近期成功、待整理和存储信息。控制连接失败但运行锁仍持有时返回 `running:null`、`state:"unreachable"` 及非零退出码，避免把连接故障误报为停止。 |
| 6. 无效日期报错语言不同 | 成立。统一中文日期格式提示；其他常见参数错误也通过同一中文错误出口处理。 |
| 7. 多余位置参数被忽略 | 成立。所有使用共享选项解析器的命令拒绝多余位置参数。未增加 yesterday/-1 等别名：已有 `--date YYYY-MM-DD` 明确表达日期。 |
| 8. 未知命令、选项英文且无指引 | 成立。未知选项说明查看帮助；未知命令仅在编辑距离足够近时建议候选，避免给无关输入强行推荐命令。 |
| 9. 空日记缺少停止和历史提示 | 成立。说明后台状态；最近七天有已有报告时给出显式 `today --date` 命令，不启动记录或模型请求。 |
| 10. 数据目录杂项、空日志及权限 | 杂项来源未确认；零字节日志在没有错误输出时是正常现象。父目录 0700 已限制访问，日志 0644 仍值得统一：安装/启动后台时预建或收紧为 0600，保留内容、拒绝日志符号链接。实现不删除 `.DS_Store`/预览或既有日志内容。 |

## 其他建议

- 日记过长：采纳摘要、主要任务、默认 20 条和 `--full` / `--limit`。JSON 保持完整，活动证据不因显示限制丢失。
- 相邻同名活动合并：不按标题合并。相同标题不保证同一任务，也不能跨未知间隔推导连续性；摘要复用已有 task_id 的时间汇总，详细记录保留原始证据。
- 碎片标签 Top 10：属于呈现取舍，尚未认定为功能缺陷。隐藏标签会改变完整筛选入口，需要结合排序、筛选和打印验证后另行决定；本轮保留报告交互。
- report 自动回退日期：不采纳。默认今天应如实展示今天，静默切换到历史日期容易误读；已有显式日期选择，空日记现在也提示近期可选日期。

## 验证方法与边界

使用独立临时数据、合成卡片/图片、假的 Claude/Hermes 可执行程序，以及注入的原生启动回调。覆盖停止状态 JSON、控制异常、日期/选项/位置参数、未知与短时长、日记摘要/显示限制/完整 JSON、pending 文案、时限配置、最终事件解析、失败通知白名单和日志权限。先复现失败，再验证修复。

未调用真实模型、录制用户屏幕、启动或修改正式安装。完整测试中的已有 HTTP 夹具需要本地 TCP 监听；受限环境禁止 bind 时应单独报告，不能将该错误归因于产品。macOS 原生硬件查询、真实 LaunchServices/TCC、真实 Windows 运行和模型服务可用性仍需相应环境验证。
